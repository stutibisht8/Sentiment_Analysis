# Sentiment Analysis

A modern Machine Learning based application for analyzing customer reviews and understanding customer sentiment.

The application classifies reviews as Positive, Negative, or Neutral and provides confidence scores, probability distribution, customer ratings, and experience-based insights.

## Features

- Customer Review Sentiment Analysis
- Positive, Negative and Neutral Classification
- Sentiment Probability Distribution
- Prediction Confidence Score
- Customer Rating Analysis
- Rating and Sentiment Mismatch Detection
- Delivery Feedback Analysis
- Packaging Feedback Analysis
- Customer Support Feedback Analysis
- Product Quality Feedback Analysis
- Individual Experience Analysis
- Customer Insights
- Bulk CSV Sentiment Analysis
- Sentiment Distribution Visualization
- Recent Analysis History
- CSV Result Download

## Customer Experience

The application allows customers to share feedback about different areas:

- Delivery
- Packaging
- Customer Support
- Product Quality

Each category can be analyzed separately to understand the sentiment of the customer's experience.

## Sentiment Analysis

The application provides:

**Sentiment:** Positive / Neutral / Negative

**Confidence Score:** Indicates the model's confidence in the prediction.

**Probability Distribution:** Displays the probability of each sentiment class.

**Customer Rating:** Allows users to provide a rating from 1 to 5.

**Consistency Check:** Compares the customer rating with the predicted sentiment.

## Bulk Analysis

Users can upload customer review datasets in CSV format and perform Sentiment Analysis on multiple reviews.

The analyzed results include sentiment predictions and confidence scores and can be downloaded as a CSV report.
